# 統計検定準一級 学習環境

このプロジェクトは、統計検定準一級の学習用に構築された環境です。
Markdownで記述された学習ノートをStreamlitアプリケーションを通じて閲覧・学習することができます。

## 環境構築

開発にはDev Containersを使用しています。以下の手順で環境をセットアップしてください。

1. **前提条件**:
    - Docker Desktop または OrbStack がインストールされていること
    - VS Code と Dev Containers 拡張機能がインストールされていること

2. **セットアップ**:
    - VS Codeでこのプロジェクトフォルダを開きます。
    - 左下の緑色のアイコン、またはコマンドパレット (`Cmd+Shift+P`) から "Dev Containers: Reopen in Container" を選択します。
    - コンテナのビルドとセットアップが自動的に行われます。

## 使い方

コンテナ起動後、以下のコマンドでStreamlitアプリケーションを起動します。

```bash
streamlit run main.py
```

ブラウザでアプリケーションが開き、`notes/` ディレクトリ内の学習ノートを閲覧できます。
