# 第25章　因子分析・グラフィカルモデル

> [!IMPORTANT]
> **【準1級での学習深度と対策】**
> 因子分析は主成分分析との違い（誤差項の有無）がよく問われます。
>
> 1.  **因子分析モデルの構造（必須）**:
>     観測変数 = 共通因子 + 独自因子 ($x = \Lambda f + e$)。独自因子の存在により、相関行列の対角成分が1にならない（共通性になる）ことを理解しましょう。
> 2.  **因子の回転**:
>     因子負荷量の解釈を容易にするための操作（バリマックス＝直交、プロマックス＝斜交）。回転してもモデルの適合度は変わらない点に注意。
> 3.  **グラフィカルモデル**:
>     無向グラフにおいて、変数の独立性が「偏相関行列（精度行列の逆行列）の成分が0」であることに対応するという点を押さえましょう。

## 1. 因子分析 (Factor Analysis)
観測された多数の変数の背後にある、共通の「潜在的な要因（因子）」を探る手法。
（例：国語・数学・英語のテスト点数 $\to$ 「言語能力因子」「論理的思考因子」で説明）

### 因子分析モデル
観測変数ベクトル $x = (x_1, \dots, x_p)^T$ （標準化済みとする）に対して、$m$ 個の共通因子 $f = (f_1, \dots, f_m)^T$ を仮定します。

$$
x_i = \lambda_{i1} f_1 + \dots + \lambda_{im} f_m + e_i
$$
または行列で
$$
\mathbf{x} = \Lambda \mathbf{f} + \mathbf{e}
$$

- $\lambda_{ij}$: **因子負荷量 (Factor Loading)**。第 $j$ 因子が第 $i$ 変数に与える影響力（相関係数に相当）。
- $e_i$: **独自因子 (Unique Factor)**。その変数固有の変動。
- **仮定**: $V[f_j]=1, E[f_j]=0$, 因子間・因子と独自因子間は無相関（直交モデルの場合）。

### 共通性と独自性
変数の分散（標準化しているので1）を分解します。
$$
V[x_i] = \sum_{j=1}^m \lambda_{ij}^2 + V[e_i] = 1
$$
- **共通性 (Communality)** $h_i^2 = \sum \lambda_{ij}^2$: 共通因子によって説明できる割合（決定係数のようなもの）。
- **独自性 (Uniqueness)** $u_i^2 = V[e_i]$: 独自因子の分散。

### 因子の回転
因子負荷量のパターンを解釈しやすくするために、軸を回転させます（モデルの適合度は変わりません）。
- **単純構造**: 各変数が特定の因子のみに高い負荷を持つ状態を目指す。
- **バリマックス回転 (Varimax)**: 因子軸の直交性を保ったまま回転（直交回転）。
- **プロマックス回転 (Promax)**: 因子間の相関を許容して回転（斜交回転）。より現実に近い単純構造が得られやすい。

> [!NOTE]
> **主成分分析との違い**
> - **PCA**: 観測変数の分散（全情報）を合成変数に縮約する。誤差項を含まない（$y = w^T x$）。
> - **因子分析**: 観測変数の背後にある共通原因を探る。独自因子（誤差）を分離する（$x = \Lambda f + e$）。

## 2. 共分散構造分析 (SEM) / パス解析
変数間の因果関係を**パス図**で表現し、相関関係や回帰係数を推定する手法。

- **構造方程式**:
  例：$Z = aX + bY + e$
- **パス係数の分解**:
  観測される相関係数を「直接効果」と「間接効果」などに分解して解釈します。

## 3. グラフィカルモデル
変数間の依存関係（条件付き独立性）をグラフ（ノードとエッジ）で表現する手法。

### 無向グラフと条件付き独立
変数 $X_1, \dots, X_p$ が多変量正規分布に従うとき、
- **相関係数** $\ne 0$ $\iff$ 変数間に相関がある。
- **偏相関係数** $\ne 0$ $\iff$ 他の変数を与えたもとで、直接的な依存関係がある（エッジがある）。

精度行列（分散共分散行列の逆行列 $\Sigma^{-1}$）の $(i, j)$ 成分が 0 ならば、変数 $i$ と $j$ は**条件付き独立**であり、グラフ上でエッジを結びません。
