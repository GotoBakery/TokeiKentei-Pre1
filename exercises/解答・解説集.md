## 第1部：基本と確率分布

### [問1] ベイズの定理
**解答: 約 1.94%**

**解説:**
事象 $D$ (病気), $H$ (健康), $P$ (陽性) とする。
$P(D) = 0.001, P(H) = 0.999$
$P(P|D) = 0.99$ (感度), $P(P|H) = 0.05$ (偽陽性)

ベイズの定理より：
$$
P(D|P) = \frac{P(P|D)P(D)}{P(P|D)P(D) + P(P|H)P(H)} = \frac{0.99 \times 0.001}{0.99 \times 0.001 + 0.05 \times 0.999}
$$
$$
= \frac{0.00099}{0.00099 + 0.04995} = \frac{0.00099}{0.05094} \approx 0.0194
$$
直感的には、陽性者51人のうち本物の病人は1人程度、という「基準率の錯誤」に注意が必要です。
-> 参照: `notes/01_事象と確率.md`

### [問2] ヤコビアン
**解答: $1/2$**

**解説:**
$u = x+y, v = x-y$ $\implies$ $x = (u+v)/2, y = (u-v)/2$。
ヤコビアン $J = \det \begin{pmatrix} \frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\ \frac{\partial y}{\partial u} & \frac{\partial y}{\partial v} \end{pmatrix} = \det \begin{pmatrix} 1/2 & 1/2 \\ 1/2 & -1/2 \end{pmatrix} = -\frac{1}{4} - \frac{1}{4} = -\frac{1}{2}$。
確率密度関数の変換には絶対値を用いるため $|J| = 1/2$。
-> 参照: `notes/04_変数変換.md`

### [問4] ガンマ分布とベータ分布
**解答: 2**

**解説:**
ベータ分布 $Be(\alpha, \beta)$ の期待値は $\frac{\alpha}{\alpha + \beta}$ です。
分母が和になる点を覚えておきましょう。

## 第2部：推定・検定・分散分析

### [問5] 第一種・第二種の過誤
**解答: 4**

**解説:**
- $\alpha$: 第一種の過誤（生産者リスク）
- $\beta$: 第二種の過誤（消費者リスク）
- $1 - \beta$: **検出力**（正しく $H_0$ を棄却できる確率）
-> 参照: `notes/10_検定の基礎と検定法の導出.md`

### [問6] 尤度比検定の自由度
**解答: 4**

**解説:**
自由度 ＝ (全パラメータ空間の次元) - (帰無仮説の次元) ＝ 制約の数。
カテゴリ数 $k=5$ の確率は総和が1なので自由なパラメータは $5-1=4$。
帰無仮説ですべての確率が固定される（自由なパラメータ0）。
よって自由度は $4 - 0 = 4$。
または、「$p_1=0.2, \dots, p_4=0.2$」という4つの独立な等式制約（$p_5$は自動決定）があるため自由度4。
-> 参照: `notes/12_一般の分布に関する検定.md`

### [問7] ノンパラメトリック検定
**解答: ウィルコクソンの順位和検定, 2**

**解説:**
2群の差（対応なし）のノンパラメトリック検定は「ウィルコクソンの順位和検定（マン・ホイットニーのU検定）」です。
同順位（タイ）がある場合は、それらの順位の**平均値**（例えば4位と5位がタイなら4.5位）を割り当てて計算します。
-> 参照: `notes/13_ノンパラメトリック法.md`

### [問8] 分散分析表
**解答: 1**

**解説:**

## 第3部：多変量解析・モデル・その他

### [問9] 回帰診断
**解答: 多重共線性 (Multicollinearity), 2**

**解説:**
説明変数同士の相関が高いと $X^TX$ が特異に近づき、逆行列計算が不安定になります。これを多重共線性（マルチコ）と呼びます。
VIF > 10 などの場合は、**相関の高い変数の片方をモデルから除去する**のが一般的な対処法です。
-> 参照: `notes/16_重回帰分析.md`

### [問10] 寄与率
**解答: 0.93 (93.3%)**

**解説:**
全変動（固有値の和）は $1.8 + 1.0 + 0.2 = 3.0$。
第2主成分までの累積寄与率は $\frac{1.8 + 1.0}{3.0} = \frac{2.8}{3.0} \approx 0.933$。
（相関行列を用いているため固有値の和は変数の数「3」に一致します）
-> 参照: `notes/22_主成分分析.md`

### [問11] 判別分析の評価指標
**解答: 1**

**解説:**
- **感度 (Sensitivity)** = TP / (TP + FN) = 90 / (90 + 20) = 90 / 110 $\approx 0.818$
- **特異度 (Specificity)** = TN / (TN + FP) = 880 / (880 + 10) = 880 / 890 $\approx 0.989$
感度は「病気の人を正しく発見できる確率」、特異度は「健康な人を正しく健康と言える確率」です。
-> 参照: `notes/23_判別分析.md`

### [問12] オッズ比の信頼区間
**解答: 3**

**解説:**
対数オッズ比の標準誤差は $SE = \sqrt{\frac{1}{a} + \frac{1}{b} + \frac{1}{c} + \frac{1}{d}}$ です。
各セルの度数の**逆数の和**のルートをとります。
-> 参照: `notes/28_分割表.md`

### [問13] モデル選択
**解答: 2**

**解説:**
BICのペナルティ項は $k \ln n$ です。サンプルサイズ $n$ が大きいとき（$n > e^2 \approx 7.4$）、$\ln n > 2$ となるため、AICのペナルティ ($2k$) よりも大きくなります。
つまり、BICの方が**変数を増やすことに対して厳しい**ため、よりシンプルなモデルが選ばれやすくなります。
-> 参照: `notes/30_モデル選択.md`

### [問14] ベイズ法
**解答: 2**

**解説:**
共役事前分布の更新則です。ベータ乱数において、成功数 $x$ を第一パラメータ $\alpha$ に、失敗数 $n-x$ を第二パラメータ $\beta$ に加算します。
$Be(\alpha + x, \beta + n - x)$。
-> 参照: `notes/31_ベイズ法.md`
